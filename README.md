# Paceline — DCS × GDG Web Development Recruitment Task
A responsive recreation of the Paceline running and e-commerce website, developed as part of the DCS × GDG Web Development Recruitment Task.
## Live Demo
[View the Live Website](https://i-nithi.github.io/Paceline-DCS-WEB-DEV-Recruitment-Task/)
## About the Project
This project recreates the design and layout of the provided Paceline website reference while implementing the pages and sections using front-end web technologies.
The website includes:
- Home page
- About page
-Both pages include the required sections, fulfilling the core purpose of the website.
## 🛠️ Technologies and Tools Used
- HTML5
- CSS3
- JavaScript
- Git & GitHub
Features & Implementation
**Creativity:** Creative recreation of the provided Paceline design with our own implementation.
**Code Quality:** Clean, structured, readable, and well-organized HTML, CSS, and JavaScript.
**Functionality:** Functional navigation, links, and interactive elements across the website.
**Responsiveness:** Responsive layout optimized for desktop, tablet, and mobile screens.
**Performance:** Improved performance through WebP image optimization and efficient loading.
**Accessibility:** Accessible implementation using semantic HTML, descriptive `alt` text, and accessible controls.
